# SAGA – Sistema Automatizado de Gerenciamento de Acessos

Trabalho de Conclusão de Curso (ADS) – FATEC Santana de Parnaíba.

Sistema web que automatiza o controle de entrada e saída de pessoas no campus, validando em tempo real a carteirinha (código de barras) e a biometria, em conformidade com a LGPD.

**Tecnologias previstas:** Python (back-end) e MySQL (banco de dados).

## Estrutura

| Pasta | Conteúdo |
|---|---|
| `docs/relatorio` | Relatório do TCC 1 (Word e PDF) |
| `docs/requisitos` | EAP, diagrama de causas e efeitos, requisitos, regras de negócio, backlog e gráficos Burndown/Burnup |
